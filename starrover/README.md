# StarRover firmware

Reserved for StarRover builds.

Nothing is published here yet. Before the first release, record in this file:

- how the product is updated (BLE/MCUboot, Wi-Fi upload, or something else),
- whether separate variants or hardware generations exist and whether they are interchangeable,
- the filename convention, and where the app reads the version from.

The app will not offer firmware it cannot identify, so those conventions need settling before a
binary is useful here rather than after.
