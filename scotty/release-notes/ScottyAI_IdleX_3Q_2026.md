## Customer changelog

- Improved switching into camping mode - Scotty now waits until the low-side voltage has dropped below the camping set point before switching.
- The Tune page is now password protected.
- Two or more Scotty units on the same CAN bus can now be told apart - each shows its own name.
- Added voltage calibration on the Feature In cable; Feature In is now used as an analogue input and its enable settings have been removed from the Tune page.
- Default settings updated for the IdleX 12V 1500W charger.
- Added an error log to help Safiery Support diagnose faults.
- Various reliability improvements.

## Compatibility

- Applies to Scotty AI IdleX units only - the firmware version on your Scotty's home screen should start with 4.0.1 or show IdleX.
- Do not install on any other Scotty model - the wrong firmware can permanently damage the unit.
- After updating, check your settings on the Tune and Advanced pages are still correct before using the unit.
- If you are unsure which Scotty you have, contact Safiery Support before updating.
